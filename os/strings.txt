# os/strings.txt - every message and name of the assembly Y1/OS (y1os.asm), one per line: LABEL "text".
# mkstrings.py turns each into `LABEL: DB b,b,...,0` (numeric bytes: the assembler upper-cases its source lines,
# so DB "text" would lose the lower case) in build/asm/y1os_str.inc, which y1os.asm INCLUDEs. The text is exactly
# what y1os.c prints (the transcripts in tests/os are the contract); only the banner's version differs.
# No escapes are needed; labels are at most 29 characters. Lines starting with # are comments.

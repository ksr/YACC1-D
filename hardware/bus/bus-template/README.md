# bus/bus-template

`eagle/v3.2/Bus Template V3.2.sch` (2020-11-29): the schematic-only template every 2020-generation card starts
from – the bus connector symbol with all 96 signals named. **This is the canonical signal naming** (C3–C6 =
ADDR-REG-ID0..3). Older templates V3.0/V3.1 (RD/LD naming, for the retired Address+TMP card) are in
`archive/superseded-revisions/`. The blank card V3.1 predates this template; see `../blank-card/`.

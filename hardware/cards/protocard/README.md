# cards/protocard — Prototyping card

A bus card with the 96-pin connector, power LED and a prototyping area brought out on 0.1" header rows
(3 x 20 and 3 x 12 positions). 178 x 114 mm, two layers. Designed 2016-07-14 for the gen-1 bus and unchanged
since; the same connector and bus, so it is still the protocard for the 2020 machine.

- `eagle/v1.0/` – **the built card**, the only version. `fab/gerbers.zip` is what went to the board house (2016);
  the extracted copy beside it was dropped 2026-09-20 as identical. Drill/photoplot logs alongside.
- The gen-1 backups also hold a "ProtoCard-V1.1" working folder whose schematic is byte-identical to this one.
